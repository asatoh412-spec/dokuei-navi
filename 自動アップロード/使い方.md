# 読影ナビ（dokuei-navi）の自動アップロード

街歩きで使っている仕組みと同じもの。作業の場がこのフォルダーにファイルと push-request.txt を置くと、launchd が GitHub の dokuei-navi に上げる。

- リポジトリ: https://github.com/asatoh412-spec/dokuei-navi （GitHub Pages で公開）
- 中身: 岩原先生用の PWA（iwahara/）と、自分用 APK の差分更新データ（au/、暗号化済み）
- 作業の場は `iwahara-source.tar.gz` → `iwahara/`、`au-source.tar.gz` → `au/` の形で置く
- 結果は auto-push.log

## 導入（一度だけ。ターミナルで）
既に GitHub にあるリポジトリを、このフォルダーにつなぐ形で導入する。

```
git clone https://github.com/asatoh412-spec/dokuei-navi.git /tmp/dn && mv /tmp/dn/.git ~/読影ナビ/ && rm -rf /tmp/dn && cd ~/読影ナビ && git reset -q --hard && sh 自動アップロード/install.sh && git add -A && git commit -qm "自動アップロードを追加" && git push
```

最後の push でユーザー名（asatoh412-spec）とトークンを聞かれる。トークンは dokuei-navi 用の fine-grained token（Repository access に dokuei-navi、Contents を Read and write）。

## 止める
`launchctl unload ~/Library/LaunchAgents/<項目名>.plist`（項目名は install.sh の最後に表示される）
